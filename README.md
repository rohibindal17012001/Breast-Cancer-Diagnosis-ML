# Breast-Cancer-Diagnosis-ML
Machine learning models for breast cancer diagnosis using Wisconsin dataset

This project implements an end-to-end machine learning pipeline for breast cancer diagnosis using the Wisconsin Breast Cancer dataset. It includes exploratory data analysis (EDA), feature scaling, train–test splitting, and the training of multiple supervised learning models such as Logistic Regression, K-Nearest Neighbors, Gaussian Naive Bayes, and Gradient Boosting. Model performance is evaluated using accuracy, confusion matrices, classification reports, and ROC curves to identify the most effective approach for reliable and early cancer detection.
